## Parent

[Cover Letter Drafts and Examples PRD](../prds/cover-letter-drafts-and-examples.md)

## What to build

Prototype where the Cover Letter workflow should sit relative to the existing CV workspace in an Application Package. The current assumption is that Cover Letter work is available once the Application Package exists and appears after the CV workspace, but this placement is provisional and should be validated before the main implementation locks it in.

The slice should produce a concrete local prototype or documented UI decision that a later implementation slice can follow.

## Acceptance criteria

- [ ] The prototype shows how a Job Seeker reaches Cover Letter work from an Application Package.
- [ ] The prototype demonstrates the relationship between the CV workspace and Cover Letter workspace.
- [ ] The decision records whether Cover Letter work appears after the CV workspace or somewhere else.
- [ ] The decision preserves that a Cover Letter Draft can be created without an existing CV Draft.
- [ ] The outcome is documented so the implementation slice can proceed without another placement decision.

## Blocked by

None - can start immediately.
